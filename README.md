# Igor Dabić

**DevOps & Linux Systems Engineer** · Zagreb, Croatia

I build and run Linux infrastructure, and the work I enjoy most is moving it: on-prem ↔ cloud migrations, legacy modernization and zero-downtime cutovers. Most recently I led the migration of four Ministry of Justice applications into the Croatian Government Cloud with zero downtime.

At home I run a Proxmox lab provisioned with Terraform and Ansible, plus a GPU server (2× AMD Radeon RX 7900 XTX on ROCm) for local LLMs. I use Claude Code and the pi coding agent every day, and the projects below come out of that lab.

## Projects

| Project | What it does |
|---|---|
| [**hyper**](https://github.com/TheLoomLabs/hyper) | Infrastructure automation that an AI agent writes and a human reviews. A Go CLI: `hyper check` validates offline, `hyper review` shows the change against the last run, and nothing runs until it is merged. |
| [**pi-unsloth**](https://github.com/TheLoomLabs/pi-unsloth) | Unsloth Studio as a first-class provider for the pi coding agent: local models with per-model tuned settings, live VRAM in the status line and GPU-aware model sizing. Verified on Linux with ROCm. |
| [**pi-dr**](https://github.com/TheLoomLabs/pi-dr) | Deep research for pi. It drafts a plan, you approve it, then it searches a self-hosted SearXNG instance and writes a report that cites only the sources it actually fetched. |
| [**EMR**](https://github.com/TheLoomLabs/EMR) | A Chrome/Firefox extension that files incoming Croatian e-invoices (eRačun) from the MIKROeRAČUN portal and bundles a month of them for your accountant. |
